# YunoHost wishlist board

Personal reference for what to package next. Generated by `sync.py` (daily GitHub Action) from the [official wishlist](https://apps.yunohost.org/wishlist). Upstream churn column = days between the two latest upstream releases.

**Workflow**

1. New wishlist requests appear under **To categorize** (marked `NEW`) — nothing gets lost.
2. To categorize one, move its line into `categorize.toml` (e.g. `myapp = "multimedia"`) and commit.
3. The Action regenerates this README within a day (or run `python sync.py` manually).

Stability tags (age of latest release, or latest commit where a forge has no releases): untagged = released within 1y · `slow-releases` = no release for 1-2y · `quiet` = 2-5y · `dormant` = 5y+ · `unknown` = no public release/commit data.
